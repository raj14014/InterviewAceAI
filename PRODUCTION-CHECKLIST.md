# Production Checklist

- [ ] `npm install`
- [ ] `npm run typecheck`
- [ ] `npm run build`
- [ ] `npm test`
- [ ] MongoDB Atlas configured
- [ ] Strong JWT_SECRET configured
- [ ] CLIENT_URL configured to frontend URL
- [ ] VITE_API_URL configured to backend `/api`
- [ ] Real AI provider configured
- [ ] HTTPS enabled
- [ ] CORS restricted to frontend origin
- [ ] Rate limits reviewed
- [ ] Upload storage configured for production
- [ ] Resume PDF/DOCX extraction service configured
- [ ] Sandboxed code runner deployed before enabling code execution
- [ ] Error monitoring/logging configured
- [ ] Backup/restore tested
